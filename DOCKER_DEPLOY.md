# 🐳 Docker Deployment (Universal - überall!)

Docker funktioniert auf **jedem Server**: AWS, DigitalOcean, Linode, Render, Fly.io, etc.

## Option 1: Lokal mit Docker Compose testen

```bash
cd /Users/dylanfregin/.claude/worktrees/reception-agent-dev

# .env mit API Keys erstellen
cp .env.example .env
# Dann Keys eintragen...

# Mit PostgreSQL lokal starten
docker-compose up -d

# Logs anschauen
docker-compose logs -f app

# Stoppen
docker-compose down
```

**Adresse:** http://localhost:3000

## Option 2: Auf Render.com deployen (Super einfach!)

Render ist wie Heroku - automatisches Deployment!

### Schritt 1: GitHub pushen

```bash
cd /Users/dylanfregin/.claude/worktrees/reception-agent-dev

# Falls noch nicht gepusht
git remote add origin https://github.com/YOUR_USERNAME/reception-agent-bot.git
git branch -M main
git push -u origin main
```

### Schritt 2: Auf Render.com deployen

1. Gehe zu: https://render.com
2. Sign Up / Log In
3. "+ New +" → "Web Service"
4. GitHub Repo wählen: `reception-agent-bot`
5. Settings:
   - **Name:** reception-agent-bot
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Production
6. "+ Add PostgreSQL"
7. Environment Variables:
   ```
   DATABASE_URL=<auto-generated by Render>
   ANTHROPIC_API_KEY=sk-ant-...
   OPENAI_API_KEY=sk-proj-...
   SENDGRID_API_KEY=SG....
   SENDER_EMAIL=sales@yourcompany.com
   SENDER_NAME=Receptionist AI
   NODE_ENV=production
   ```
8. "Create Web Service"

**Deine App läuft unter:**
```
https://reception-agent-bot.onrender.com
```

## Option 4: Auf AWS deployen

### Mit Elastic Beanstalk (einfach):

```bash
# EB CLI installieren
brew install aws-elastic-beanstalk

# Initialisieren
eb init -p node.js-18 reception-agent-bot

# Environment Variables in .ebextensions/env.config:
option_settings:
  aws:elasticbeanstalk:application:environment:
    ANTHROPIC_API_KEY: sk-ant-...
    OPENAI_API_KEY: sk-proj-...
    SENDGRID_API_KEY: SG....
    NODE_ENV: production

# Deployen
eb create reception-agent-bot-env
eb deploy
```

**URL:** https://reception-agent-bot-env.elasticbeanstalk.com

## Option 5: Mit Docker Image direkt pushen

```bash
# Docker Image bauen
docker build -t reception-agent-bot .

# Image taggen
docker tag reception-agent-bot:latest your-registry/reception-agent-bot:latest

# Zu Registry pushen (z.B. Docker Hub)
docker push your-registry/reception-agent-bot:latest

# Dann auf jedem Server deployen:
docker pull your-registry/reception-agent-bot:latest
docker run -d \
  -e DATABASE_URL=postgres://... \
  -e ANTHROPIC_API_KEY=... \
  -p 3000:3000 \
  your-registry/reception-agent-bot:latest
```

## Nach Deployment: DB Migrations

Nachdem App deployed ist:

```bash
# Bei Render:
# Dashboard → "Shell" Tab
psql $DATABASE_URL -f db/migrations/001_create_leads_table.sql
psql $DATABASE_URL -f db/migrations/002_create_campaigns_table.sql

# Bei DigitalOcean/AWS - SSH in App:
ssh ec2-user@your-app-ip
psql $DATABASE_URL -f db/migrations/001_create_leads_table.sql
```

## Troubleshooting

**App startet nicht?**
→ Schau Logs: `heroku logs --tail` oder Render Dashboard

**DB Connection Error?**
→ Überprüfe DATABASE_URL Environment Variable

**Port Error?**
→ App muss auf `process.env.PORT` hören (✅ schon in src/index.js)

**API Key Fehler?**
→ Überprüfe alle Environment Variables sind gesetzt
